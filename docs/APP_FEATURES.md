# 콜 메시지 — 기능 목록

이 문서는 현재 앱에서 제공하는 사용자 기능과 Android 자동 응답 동작을 정리합니다.

---

## 1. 홈

| 기능 | 설명 |
|------|------|
| 자동 응답 ON/OFF | 스위치로 활성화. 켤 때 전화·SMS·알림 등 필수 권한 확인 및 요청 |
| 활성 템플릿 동기화 | 켜기/끄기 시 Android에 문구·이미지·enabled 상태 동기화 |
| 빈 문구 방지 | 활성 템플릿 문구가 비어 있으면 켜기 불가, 메시지 설정으로 안내 |
| 최근 기록 | 자동 응답 **성공** 이벤트 목록 (최대 **30건**, 초과 시 오래된 항목 삭제) |
| 기록 표시 | SMS: 「문자 전송 완료」, MMS: 「이미지 전송 완료」; 한국어 시간(오늘/날짜) |
| 번호 마스킹 | 설정에서 켜면 홈 기록의 전화번호를 가려 표시 |
| 당겨서 새로고침 | 기록·enabled 상태 다시 로드 |

---

## 2. 메시지 설정

| 기능 | 설명 |
|------|------|
| SMS / MMS 모드 | 세그먼트로 구분. MMS는 템플릿에 이미지가 있을 때 |
| 응답 문구 편집 | 최대 **200자**, 글자 수 표시 |
| 저장 템플릿 | 최대 **10개**. 목록 라벨은 문구 **앞 20자** |
| 템플릿 선택 | 선택 시 **즉시 활성** + Android 동기화 |
| 템플릿 추가·편집·삭제 | 메뉴로 문구 수정·삭제 |
| MMS 이미지 | 템플릿당 최대 **3장**, 갤러리에서 선택 |
| 이미지 최적화 | 저장 전 리사이즈·압축 (긴 변 1280px, 목표 용량 등) |
| 이미지 저장 | 앱 전용 문서 디렉터리로 복사 후 경로 저장 |
| 테스트 발송 | 디버그 빌드에서 지정 번호로 테스트 SMS/MMS |

**발송 규칙:** 활성 템플릿에 **유효한 이미지 파일이 있으면 MMS**, 없으면 **SMS**. 여러 장 설정 시 Android MMS 경로에서 다중 이미지 지원.

## 3. 설정

| 기능 | 설명 |
|------|------|
| 배터리 최적화 | 안내 + 시스템 배터리 예외 설정 화면 열기 |
| 권한 | 전화, SMS, 사진·미디어 상태 표시 및 요청 |
| 시작 시 자동 실행 | OFF면 부팅 후 감시 서비스 자동 시작 안 함 |
| 최근 기록 번호 마스킹 | 홈 기록 표시용 |
| 번호별 쿨다운 | ON: 동일 번호 **발송 성공 후 5분** 동안 재발송 안 함 (SMS/MMS 동일 이력) |
| 앱 정보 | 앱 버전 표시 |

## 4. 부재중 감지·자동 발송 (Android)

| 기능 | 설명 |
|------|------|
| 포그라운드 감시 서비스 | 자동 응답 ON 시 상시 알림 + 백그라운드 감시 |
| 통화 기록 감시 | 통화 기록 변경 감지 + 지연 재시도 (0, 500, 1500, 3000 ms) |
| 전화 상태 수신 | 울림 후 받지 않고 종료 시 부재중 판단 + 재시도 (0~5000 ms) |
| 처리 범위 | 최근 **5분** 부재중 로그, 최대 **10행** 검사 |
| 통화당 1회 | 통화 로그 ID **클레임**으로 중복 발송 방지; 처리 ID 목록 유지 (최대 200) |
| 번호 잠금 | 동일 번호로 **진행 중** 발송이 있으면 추가 발송 스킵 |
| 자체 발송 무시 | 앱이 보낸 SMS/MMS로 인한 기록 변경만으로 재감지하지 않음 |
| 번호 정규화 | 비교 시 숫자와 `+`만 유지 |
| 무효 번호 | 빈 번호·비공개 등은 발송하지 않음 |
| SMS | 장문은 분할 발송 |
| MMS | PDU 생성, 용량 초과 시 JPEG 압축, 통신사 결과 대기 (최대 약 30초) |
| UI 비블로킹 | 발송·MMS 대기가 메인 스레드를 막지 않음 |
| 부팅 후 재시작 | 부팅 완료 수신; **시작 시 자동 실행** ON이고 자동 응답 ON이면 서비스 재시작 |

- MethodChannel: `com.example.missed_call_responder/auto_reply`
