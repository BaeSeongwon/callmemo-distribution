# 콜 메시지 — 앱 소개

**콜 메시지**(Missed Call Responder)는 Android용 **부재중 전화 자동 응답** 앱입니다. 전화를 받지 못했을 때, 미리 준비한 문구로 **SMS**를 보내거나, 이미지가 설정되어 있으면 **MMS**로 보냅니다.

## 무엇을 하는 앱인가요?

바쁠 때나 회의 중에 놓친 전화에 “지금은 통화가 어렵습니다” 같은 안내를 **자동으로** 보내고 싶을 때 사용합니다. 사용자는 앱에서 응답 문구와(선택) 이미지를 저장하고, **자동 응답**을 켜 두면 백그라운드에서 부재중 전화를 감지해 설정한 내용을 발송합니다.

## 어떻게 만들어졌나요?

- **Flutter**: 설정 화면, 템플릿·기록 관리, 권한 안내, Android와의 연동
- **Android 네이티브(Kotlin/Java)**: 부재중 감지, 포그라운드 감시 서비스, SMS/MMS 실제 발송

자동 응답의 **실제 동작은 Android에서만** 지원합니다. iOS 빌드는 포함될 수 있으나, 부재중 감지·문자 발송은 Android 전용입니다.

## 사용자 경험 요약

- 하단 탭 **홈 · 메시지 설정 · 설정**으로 구성된 단일 앱
- 보라색 계열(`#7C5CFF`) UI, 둥근 카드·Lucide 아이콘
- 홈에서 자동 응답 ON/OFF와 **최근 전송 기록** 확인
- 메시지 설정에서 여러 템플릿, SMS/MMS, 이미지 첨부 관리
- 설정에서 권한, 배터리 최적화, 부팅 후 자동 실행, 번호 마스킹·쿨다운 등 조정

## 베타 안내

현재 빌드는 **베타 테스트** 단계입니다. 앱을 **처음 실행**(콜드 스타트)할 때 베타 안내 다이얼로그가 한 번 표시되며, 확인 후 같은 실행 세션에서는 다시 나타나지 않습니다. 안내 표시는 자동 응답 설정·모니터링 상태를 바꾸지 않습니다.

## 안정적인 동작을 위해

백그라운드에서 통화를 감시하려면 **전화·통화 기록·SMS·알림** 등 권한이 필요합니다. 기기가 앱을 절전시키지 않도록 **배터리 최적화 예외** 설정을 권장합니다.
